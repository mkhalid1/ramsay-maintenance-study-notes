# Glossary

Terms used in these notes and on Ramsay's pages, in plain words.

| Term | Meaning |
|---|---|
| Accumulator | A vessel that stores hydraulic fluid under pressure, to meet peak demand or absorb shock. |
| Alternate form | A different but equivalent version of a test, used for retesting. |
| Angular misalignment | Two shaft centrelines that meet at an angle. |
| Cavitation | Vapour bubbles forming and collapsing in a pump because suction pressure is too low. Sounds like gravel. |
| Centre line | A long-dash, short-dash line marking the centre of a hole, shaft or symmetric feature. |
| Check valve | A valve that allows flow one way only. |
| Contactor | An electrically operated switch for power circuits. Add an overload relay and it becomes a motor starter. |
| Cut score | The score an employer sets as the minimum to pass. Ramsay does not publish one. |
| Directional control valve | A valve that sends fluid to one port or another, for example to extend or retract a cylinder. |
| FLA | Full load amps, the current a motor draws at rated load. |
| FRL | Filter, regulator, lubricator: the standard air preparation unit, in that order. |
| GMAW | Gas metal arc welding (MIG). Consumable wire, shielding gas. |
| GTAW | Gas tungsten arc welding (TIG). Non-consumable tungsten electrode. |
| Hidden line | Short evenly spaced dashes showing an edge behind material. |
| Holding contact | A contact in parallel with a start button that keeps a coil energised after the button is released. Also called a seal-in contact. |
| Journey level | Ramsay's term for 2 to 5 years of training and experience. |
| KR-20 | A measure of how consistent a test's items are. Closer to 1 means more reliable. |
| Mechanical advantage | How many times a machine multiplies force, traded against distance. |
| Overload relay | A device that trips a motor on sustained overcurrent. |
| Parallel (offset) misalignment | Two shaft centrelines that are parallel but not in line. |
| Percentile rank | The share of other test takers you scored as well as or better than. |
| PLC | Programmable logic controller, the industrial computer that runs machine logic. |
| Positive displacement pump | A pump that moves a fixed volume per turn, such as a gear or piston pump. |
| Proctored | Supervised. All Ramsay tests are proctored. |
| Relief valve | A valve that opens at a set pressure to protect a system. |
| Scrambled version | An online test with question order randomised within each category. |
| Single phasing | Loss of one phase to a three-phase motor. |
| SKU | Ramsay's unique test code. RR means paper, OL means online. |
| Synchronous speed | The speed of a motor's rotating field: 120 x frequency / poles. |
| TIR | Total indicator reading: the full swing of a dial indicator over one turn. |
| Trainee level | Ramsay's term for 2 to 3 years of training or experience, needing 1 to 2 more. |
| Union (fitting) | A pipe fitting that lets a run be taken apart without turning the pipe. |
| VFD | Variable frequency drive, which controls AC motor speed by changing frequency. |
| Volute | The spiral casing of a centrifugal pump. |
| XIC / XIO | PLC instructions: examine if closed (true when the bit is 1) and examine if open (true when the bit is 0). |
